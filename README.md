Um perfil/diário pessoal pertencente a um ex cinéfilo chato vulgo dito cujo joao/acqua/tato. Esse site contem perfil, fundo personalizado, status, filmes favoritos, filmes que não curtiu, comentários e um diário completo de filmes/séries assistidos (com avaliação em folhas, no lugar de estrelas).

Caso queira visualizar o site/utilizar, acesse o vercel link direto: https://jafuiplaneta.vercel.app .

---

## 🎁 Um presente

> Alguns presentes se embrulham. Este foi programado.

Este site foi feito para o **Acqua**. É um presente para ele.

Não nasceu de um pinterest ou ideia de i.a. Nasceu de de um conjunto de coisas que nosso amigo acqua gosta: quem ama cinema merece um lugar que guarde não só o que assistiu, mas o que sentiu enquanto assistia, com uma pitada de natureza para se sentir em casa.

Por isso cada detalhe foi pensado para uma pessoa só. O verde de floresta, as folhas no lugar das estrelas, a foto de perfil, o fundo que dá para trocar quando bater a vontade. Até a lista **Sessão com você**, onde ficam os títulos que a gente assiste, ou ainda vai assistir, juntos.

## ✨ O que tem por dentro

| | |
|---|---|
| 🍃 **Avaliação em folhas** | De 1 a 5, porque estrela é coisa de outro site. |
| ★ **Favoritos** | A vitrine do perfil: o que não pode faltar. |
| ✕ **Não curti** | Os títulos que não passaram na peneira, com direito a justificativa. |
| 💬 **Comentários** | Cada resenha escrita vira uma entrada do diário. |
| 🎞️ **Pôster ou trailer** | Cole uma imagem ou um link do YouTube em qualquer filme ou série. |
| 📚 **Listas** | Maratonas, temas, sessões. Do jeito que fizer sentido. |
| ☁️ **Salvo na nuvem** | O diário acompanha de qualquer aparelho. |
| 🔐 **Só com login** | Um diário pessoal merece uma porta. |
